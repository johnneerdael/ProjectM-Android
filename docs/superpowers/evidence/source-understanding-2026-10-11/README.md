# Source effect understanding: SDK, random material and parametric waves

This checkpoint extends the source JSON and provides a documented standard-library
SDK/LLM skill. The product goal is recognizable effect understanding and automatic
mood grouping across9,606 presets, not exact image recreation. Whole-pack automatic
moods remain unfinished. Existing strict physical eligibility is separate from
explicitly labelled approximate LLM interpretations.

## What changed

- `preset_understanding.summarize_preset(record)` and its CLI preserve exact JSON
  fact paths/values, produce readable effect descriptions and distinguish source
  facts, approximate look/mood hypotheses and actual observations.
- `skills/understand-preset/SKILL.md` documents the interpretation/checkpoint flow.
- Shape flash records include independent stochastic material two-state ceilings,
  alpha/blend weights, init/frame refresh scope and fixed-unit-texture partials.
  Refresh opportunities are not visible flash rates or independent RNG draws.
- Radial custom waves can expose affine radius/phase recipes, source curves,
  spatial RGB ramps and an interior continuous-locus relation. Exact rational
  coefficients preserve tiny time growth; outward bounds and conservative circle
  completion avoid false numerical claims. Early expression-expansion budgets
  retain the pre-existing radial family when optional analysis abstains.
