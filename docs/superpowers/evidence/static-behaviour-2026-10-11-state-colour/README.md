## Repairs and independent review

- Distinct EEL random calls no longer cancel or imply shared grayscale; copied
  values retain identity. Exported phase/site identifiers stay deterministic.
- Stochastic colour bounds replace individual admitted material groups, then
  union every live fill and border. Constant and unknown borders are retained.
- State induction rejects embedded numerical/comparison writes whose native
  pointer aliasing invalidates value snapshots. Division honors source34's strict
  `1e-5` zero guard; intervals crossing its seam remain unresolved.
- Large shape groups use the complete native instance domain, radius/side-count
  envelopes and an unclipped polygon union upper, with zero lower support.
  Exact-rational positive-last sine-series bounds and outward conversion replace
  an insufficient final `nextafter` of a multi-step trig calculation.
- Individually finite centres/radii cannot hide an overflowing native float32
  corner addition behind zero alpha. Both overflow and finite controls pass.

Independent reviews found and then cleared the alias, border, trig rounding and
corner-addition findings. The first v8 run is retained in
`build/preset-corpus/static-behaviour-2000-2026-10-11-state-colour-v8/`; it predates
the corner guard and is not final qualification. Corrected final rows are in
`static-behaviour-2000-2026-10-11-state-colour-v8-final/`. No AAR defect was found
by these controls; they are predictor repairs.
